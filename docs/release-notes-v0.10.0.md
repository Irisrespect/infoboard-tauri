# InfoBoard v0.10.0

> 主题：**待办有了自己的窗口** —— 信息区只负责瞄一眼，正经管理搬到独立窗口，工具入口做成可分发的外置插件。

## 亮点

### 1. 待办详细管理：独立窗口

工具区点「待办」图标，弹出一个 520×700 的独立窗口（可移动、可关闭、半透明面板 alpha≈0.92，
能透出一点桌面质感但文字清晰）。窗口里能做完整的增删改：

- 添加（文本 + 截止日期，支持 `2026-12-31` 和 `7月8日` 两种写法）、行内编辑、勾选完成
- 单条删除、按状态筛选、批量清理已完成 —— 删除与清理都有 8 秒「撤销」
- 中文输入法拼字时按回车只选词、不提交
- 窗口已经开着时再点图标只是聚焦，不会重复建窗

### 2. 工具入口是可分发的外置插件

`plugins/todo-manager/` 打包为 `todo-manager-1.1.0.ibplugin`，与网盘下载器 / API 测活那批
用同一套启动器机制：插件清单里声明 `todo_window_open`，宿主只负责建窗。
换句话说，这个入口可以单独热装、单独升级，不用重装整个应用。

### 3. 信息区卡片变轻

移除每条待办后面的删除 / 编辑按钮，卡片只保留**查看、勾选、快速添加、折叠**与一键清理。
破坏性操作全部集中到独立窗口里 —— 卡片上不再有"手滑就没"的入口，
连点删除误删两条的老问题也随之消失。

### 4. 一份数据，两个窗口

待办数据层抽成单一 store（zustand），信息区卡片与独立窗口共享同一份数据；
跨窗口同步走浏览器原生的 `storage` 事件，一侧改动另一侧立刻刷新，不需要自定义事件桥。
本地数据损坏时，任一侧都不会把它覆盖成空列表（会先备份到 `todo-list.corrupt.<时间戳>`）。

## 升级说明

- 版本 **0.9.1 → 0.10.0**，下载 `InfoBoard_0.10.0_x64-setup.exe` 覆盖安装即可
- **需要单独安装工具入口**：下载 `todo-manager-1.1.0.ibplugin`，在「设置 → 插件管理」里拖进去
  （或点「选择插件包」）。不装的话工具区不会有「待办」图标，但信息区卡片照常工作
- **本地数据兼容**：仍是 `localStorage['todo-list']`，升级不影响已有待办
- **粉紫主题**：独立窗口用半透明面板（`--bg-window`，alpha 0.92），不再是全透明透桌面
