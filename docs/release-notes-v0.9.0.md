# InfoBoard v0.9.0

> 主题：**外部插件终于能带"自己的程序"了** —— 以后加功能只发一个 `.ibplugin`，用户不用重装应用。

## 亮点

### 1. 插件可以自带伴随程序（`companion`）

以前只有插件界面（`index.tsx`）能热更新，插件背后的独立程序（网盘下载器等）只能随
**安装包**发 —— 改一行 Python 都要用户重装整个 InfoBoard，`.ibplugin` 这条通道对
"启动器类插件"形同虚设。

现在：

```json
"companion": { "dir": "app", "entry": "main.py", "version": "2.1.0" }
```

- 程序打进 `.ibplugin`，导入即用；宿主优先跑插件里那份，安装包 resources 里那份退化成兜底；
- **对任何插件 id 都成立**（不再限于内置的三个），宿主任意命令 `companion_launch({id})` 即可拉起；
- 路径**只由宿主拼**（`<plugins>/<id>/app/<entry>`），命令只收 id 不收路径 ——
  插件启动不了别人的程序，也启动不了自己包外的东西；
- `kind: "exe"` 支持自带可执行文件（不需要用户装 Python）；
- 版本契约：`VERSION` 文件为唯一事实源，打包脚本校验、运行期再比一次，不一致弹提示。

### 2. 三个启动器插件全部改为自带程序

| 插件     | 版本   | 说明                             |
| -------- | ------ | -------------------------------- |
| 网盘下载 | 2.1.0  | 夸克 + 迅雷，`app/` 下 14 个文件 |
| B站下载  | 1.2.0  | yt-dlp 驱动，程序随包            |
| API      | 1.10.0 | 单文件零依赖，程序随包           |

### 3. 网盘下载器的一批修复

- **目录超过 6 层就整批下不了** → 展开改为显式队列 + 层内并发（默认 6，可调 1~16），
  25 个目录 1260ms → 253ms，文件顺序不变；到顶只跳过那棵子树并提示；
- **单目录超过 200 项静默少文件** → 按 `_page` 翻页取全；
- **深层目录 + 中文名超过 MAX_PATH** → 自动加 `\\?\` 长路径前缀（不用改注册表）；
- **迅雷转存报 `ValueError: could not convert string to float: '…Z'`** →
  `expires_at` 的 ISO 字符串统一解析（数字 / 数字字符串 / ISO / 毫秒都认），
  认不出来当作"不知道过期时间"而不是抛错。

### 4. 其它

- 新增 [`plugins/.launcher-template/`](plugins/.launcher-template/README.md)：
  启动器插件模板（复制改名 → 打包 → 拖进插件管理），带 4 条守卫测试；
- `pack-plugin.mjs` 支持 `--companion <程序目录>`：自动排除 `__pycache__` / `*.pyc` / `tools/`，
  条目 ≤ 64、解压 ≤ 8 MB（与宿主上限一致）；
- `api-probe-app/` 纳入仓库并随包发布（此前 `api_probe.py` 不在仓库里，插件只能靠手动指定）。

## 安装

下载 `InfoBoard_0.9.0_x64-setup.exe` 直接覆盖安装即可（单实例，装完自动替换）。

### 插件包（拖进「设置 → 插件管理」，不用重装应用）

- `netdisk-2.1.0.ibplugin`
- `bili-dl-1.2.0.ibplugin`
- `api-probe-1.10.0.ibplugin`
- 其余：`translate-2.2.0` / `deepseek-1.2.0` / `hello-world-1.0.0` / `system-info-1.0.0`

> 0.9.0 之前安装的插件（`netdisk` 2.0.x 等）**没有程序本体**，请一并换成上面的新包；
> 旧宿主（0.8 及更早）只认内置的三个 id，`companion` 声明会被忽略。

## 已知限制

- 启动器插件需要本机有 **Python 3.9+**（`kind: "exe"` 的插件除外）；
- 插件包解压上限 8 MB，带运行时的打包（PyInstaller 等）放不进插件包；
- 自动更新通道仍未接入（`plugins.updater` 为空），升级需要手动下载安装包。
