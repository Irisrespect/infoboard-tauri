# InfoBoard v0.9.1

> 主题：**待办插件从"能用"到"顺手"** —— 功能一个没少，但一批交互细节在真机上会咬人。

## 亮点

### 1. 中文输入法不再误提交

用拼音打「下周三交周报」，选词时按的那个回车曾经等于提交 —— 半截文本落库，还得回头改。
现在添加入口和行内编辑都判 `isComposing` / `keyCode 229`：**拼字中的回车只选词，不提交**。

### 2. 键盘 / 触屏真的能用

- **Enter 不再只是折叠卡片**：`InfoCard` 的 Enter/Space 处理只在焦点落在卡片自身时生效，
  焦点在「筛选」「一键清理」按钮上时按钮正常响应（天气卡、灵动岛同步受益）。
- **勾选框是真按钮**：`role="checkbox"`，可聚焦、可切换；删除 / 编辑按钮从"悬停才出现"
  改为常驻低透明度、悬停或聚焦时显形，命中区 24×24 —— 触屏和键盘都摸得到。
- **折叠后不再偷走 Tab**：展开区加 `inert`，收起后看不见的输入框不会被 Tab 进去盲写数据。
- 日期选择器（那个 `opacity-0` 的框）移出 Tab 序，键盘不会再被硬拽进 4 个看不见的停靠点。

### 3. 误操作可回退

- 删除单条、一键清理已完成之后弹 toast，**8 秒内点「撤销」原样恢复**（按 id 去重，不会插重复）；
- 连点删除按钮曾一次删掉两条（第一击后行上移，第二击命中顶替上来的那条），现在同一位置
  350ms 内只认第一击，键盘连删不受影响；
- 卡片不再"点哪儿都折叠"：折叠入口收敛到头部，展开区整体止泡，16px 内边距环也算在内。

### 4. 日期语义与数据安全

- 「6月20日」这类简写改为**"下一次出现"**规则：12 月底写「1月5日」不会再变成"逾期 359 天"；
  `YYYY-MM-DD` 严格按你写的年份。
- 本地数据损坏时不再被空列表覆盖：先备份到 `todo-list.corrupt.<ts>` 再提示用户，脏标记控制写盘。
- 老数据迁移不再清掉解析不了的截止日原文（如「下周三」），原样保留。
- 逾期红标接跨天定时器 + 窗口重新可见信号，不用等"碰巧重渲染"才更新。
- 已完成的任务沉底，长待办截断显示，不再把日期和删除按钮挤出可视区。

## 升级说明

- 版本号 **0.9.0 → 0.9.1**，下载 `InfoBoard_0.9.1_x64-setup.exe` 直接覆盖安装即可
  （单实例，装完自动替换）。
- **本地数据兼容**：localStorage 键仍是 `todo-list`，升级不影响已有待办；万一读到损坏数据，
  也会先备份原始内容再提示。
- 无需重装任何插件，本次改动全在宿主侧。
