## v0.6.0 — 网盘下载器（独立软件）+ 一键启动入口

本次新增一条完整的网盘下载链路：**独立软件「网盘下载器」**，以及 InfoBoard 工具区里
点一下就把它拉起来的入口。只用 Python 标准库（tkinter + urllib），**不需要 pip 安装任何东西**。

### 新功能

- **独立软件：网盘下载器**（`netdisk-app/`）
  - 自己的窗口和进程 —— 下载不再依赖 InfoBoard 面板是否开着。这一点是硬需求：
    插件跑在 WebView 里只在面板打开时运行，而网盘直链只有 5~10 分钟有效期，
    面板一关就没人换链，大文件必然下不完
  - 解析夸克分享 → 目录浏览（双击进入 / 返回上级）→ 多选或整目录**递归**下载
  - 队列显示进度/速度/状态，可取消、双击打开所在文件夹
  - 设置：保存目录、并发连接数、夸克登录态（附"关键项齐全"体检）
- **一键启动**：工具区点「☁️ 网盘下载」直接拉起独立软件，不展开中间面板
  （与截图插件同一套做法）。启动失败会弹原生错误框说明原因

### 下载引擎

- Range 探测 → **动态分片队列 + 抢占式取片**（片数 = 连接数 × 32、单片 ≥ 256KB）
  → 各线程用自己的文件句柄随机写同一文件，不需要"下完再合并"
- **直链过期自愈**：撞上 401/403/404/412 就重新解析分享，从未完成的分片继续，最多 5 次。
  换链做了**串行化** —— 直链一过期所有线程会同时撞上，各换各的会瞬间耗尽重试预算
- **429/503 全局退避**：所有线程一起静默（首次 30 秒、翻倍、上限 5 分钟）
- **慢分片抢占**：15 秒收不到字节就换条连接试

### 顺手修掉的问题

- 工具图标的激活色引用了**从未定义过**的 CSS 变量（`--color-primary`）。`stroke` 因此
  回落到 `none` —— **点中的插件图标会整个消失**（截图/设置/翻译都受影响）
- 宿主 `PluginManifest` 结构体没有 `color` 字段，外部插件 manifest.json 里写了会被
  serde 静默丢弃。具名图标在未选中时拿不到 stroke → **图标看不见**，点一下才出现
- 插件图标从彩色 emoji 换成具名线性图标 `cloud-download`，与其它工具插件风格统一

### 关于"免费高速"

- 夸克是**按连接**限速：单连接常态 100~~200KB/s，多连接可叠加（实测 512 并发 × 256KB
  可达 21~~23.7 MB/s；但存在账号级总量天花板，512 → 1024 连接几乎不再涨）
- 匿名档只能下约 50MB 以下的文件（超了报 `23018`），且**加并发无效**（按整体限速）；
  登录后同一路径可直接下 GB 级文件并能靠并发提速
- 伪 SVIP User-Agent 一类"破解"手法已被官方封堵，本软件不做也不建议做

### 已知限制

- **只实现了夸克**；蓝奏云/阿里云盘等未接入（原因见 `docs/NETDISK.md`）
- **跨次运行的断点续传没有做**：关掉软件再打开，已完成的分片不会复用
- 运行需要 Python 3.10+（自带 tkinter；Windows 官方安装包默认带）
