# 网盘下载器（独立软件）

夸克网盘分享链接 → 解析目录 → **多连接高速下载**。独立窗口、独立进程，跑起来就不受
InfoBoard 面板开关影响。

只用 Python 标准库（tkinter + urllib），**不需要 pip 安装任何东西**。

```
netdisk-app/
├── main.py                 入口：Tkinter 界面
├── netdisk/
│   ├── core.py             HTTP 客户端（cookie jar / 自动解压 / 流式读）、数据模型
│   ├── adapters.py         网盘协议：夸克（解析 → 列目录 → 免转存取直链）
│   └── downloader.py       多连接分片引擎（动态队列 / 直链自愈 / 限流退避 / 慢分片抢占）
└── tools/
    ├── smoke_download.py   引擎冒烟测试（不需要账号，起本地 HTTP 服务真跑一遍）
    └── probe_quark.py      协议探测（打真实接口，验证路径/请求体/错误码层次）
```

## 为什么做成独立软件

InfoBoard 里的插件跑在 WebView 中，**只在面板打开时运行**。网盘直链只有 5~10 分钟
有效期，大文件必然中途过期 —— 面板一关，就没人来换链，任务只能失败。
独立进程自己就能一直下、自己换链；而且不受应用 CSP 限制（插件既不能直接发请求，
也不能写文件，那两条路都得由宿主 Rust 代劳）。

## 运行

```bash
# 需要 Python 3.10+（自带 tkinter，Windows 官方安装包默认带）
python main.py

# 不想看到控制台窗口的话：
pythonw main.py
```

InfoBoard 里点 **☁️ 网盘下载 → 打开网盘下载器** 也能启动它。

## 用法

1. 粘贴夸克分享链接（`https://pan.quark.cn/s/xxxx`），有提取码就填上 → **解析**
2. 列表里选中文件或文件夹（双击文件夹进入，← 返回上一级）→ **下载选中**
   - 选文件夹会**递归**展开，并按原目录结构落盘
3. 下方队列看进度/速度/状态；可以取消、双击打开所在文件夹
4. **设置** 里改保存目录、并发连接数、夸克登录态

## 关于"免费高速"（重要）

夸克是**按连接**限速的，所以多连接能叠加 —— 这是这个软件唯一真正的加速手段：

|            | 匿名（不登录）                               | 登录后                                                 |
| ---------- | -------------------------------------------- | ------------------------------------------------------ |
| 单文件大小 | **≤ 约 50MB**（超了报 `23018`）              | 1.2GB+ 正常                                            |
| 速度       | 0.17–0.75 MB/s，**加并发无效**（按整体限速） | 单连接 ~0.12MB/s，**512 并发×256KB 可达 21–23.7 MB/s** |

所以：**想快必须登录**，并且把并发开大。登录方式见下。

> 这些数字来自本机可复现实测（见 `docs/NETDISK_PLUGIN.md` 与调研记录），
> 不是推测。速度随时段和账号波动很大，遇到"整体塌陷时段"是正常的。

## 登录夸克（把匿名档升到高速档）

1. 浏览器打开 `pan.quark.cn` 并登录
2. `F12` → **Application** → **Cookies** → `https://pan.quark.cn`
3. **只复制 quark.cn 域下的那些项**（至少要有 `__puus`），粘到「设置 → 夸克登录」
4. 点「检查」：会说"关键项齐全 ✓"或者点名缺哪个

⚠️ **不要把浏览器全部 Cookie 都粘进来**：实测整份（约 7.2KB，含大量无关域）
会被服务端直接掐断连接。只要该网盘域下的那一份（通常 20~30 项）。

## 已知限制

- **只做了夸克**（按要求）。蓝奏云/百度/阿里云盘等未接入。
- 勾选文件夹时是**递归展开**下载，不做"打包成一个 zip"。
- 断点续传只在**同一次运行内**有效：关掉软件再打开，已完成的分片不会复用，
  会重新下（要支持跨次续传得额外落一份分片完成表）。
- 夸克 Cookie 明文存在 `%APPDATA%\netdisk-downloader\config.json`，
  别把这个文件拷给别人。
- 直链过期会自动换链（最多 5 次）；换链要重新解析一次分享，会有 1~2 秒停顿。

## 自测

```bash
# 引擎：多连接拼装是否逐字节正确 / 过期换链续传 / 不支持 Range 时退回单连接
python tools/smoke_download.py

# 协议：打真实接口验证路径与错误码层次（用无效 ID，不需要账号）
python tools/probe_quark.py
```

`smoke_download.py` 全程用本地 HTTP 服务，不碰任何真实网盘，可以离线跑。
